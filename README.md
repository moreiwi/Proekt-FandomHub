# FandomHub - каталог популярных медиафраншиз

**FandomHub** - это учебный веб-проект, представляющий собой каталог популярных медиафраншиз.

Проект разрабатывается студетами 2 курса колледжа НКЭиВТ. Сайт предназначен для просмотра информации о различных медиафраншизах, их категориях, жанрах и особенностях.

## Цель проекта

Цель проекта - разработать адаптивный веб-сайт на HTML, CSS, JavaScript, который позволит вользователю просматривать каталог популярных медиафраншиз, использовать поиск, фильтрацию, сортировку.

--- 

## Описание проекта

FandomHub объединяет различные вселенные из:

- аниме;
- игр;
- хорроров;
- визуальных новелл;
- мультсериалов;
- фантастики;
- инди-проектов.

На сайте реализованы:

- каталог карточек;
- поиск по названию;
- фильтрация по категориям;
- фильтрация по жанрам;
- сортировка;
- модальное окно с подробной информацией;
- адаптивность под мобильные устройства.
